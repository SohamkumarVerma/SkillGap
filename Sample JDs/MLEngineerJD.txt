# Job Description — Machine Learning Engineer

**Job Title:** Machine Learning Engineer
**Experience:** 1–3 years
**Location:** Pune, Maharashtra / Hybrid
**Employment Type:** Full-time

### About the Role

We are looking for a **Machine Learning Engineer** to design, develop, evaluate, and deploy machine learning solutions for real-world business problems. The ideal candidate should have strong programming and mathematical fundamentals, practical experience with ML algorithms, and the ability to take models from experimentation to production.

### Key Responsibilities

* Develop and implement machine learning models for classification, regression, clustering, and prediction tasks.
* Collect, clean, preprocess, and analyze large datasets.
* Perform feature engineering and select appropriate features for model development.
* Train, validate, and evaluate ML models using suitable metrics.
* Experiment with different algorithms and optimize model performance.
* Build and maintain scalable ML pipelines.
* Deploy machine learning models through APIs and production systems.
* Monitor model performance and identify model drift or degradation.
* Collaborate with software engineers, data scientists, and product teams.
* Document experiments, models, datasets, and implementation decisions.
* Optimize ML systems for performance, scalability, and reliability.

### Required Qualifications

* Bachelor's degree in Computer Science, Computer Engineering, Data Science, Mathematics, or a related field.
* Strong proficiency in **Python**.
* Good understanding of **machine learning algorithms and concepts**.
* Experience with **NumPy, Pandas, and scikit-learn**.
* Understanding of statistics, probability, and linear algebra.
* Experience with data preprocessing and feature engineering.
* Knowledge of model evaluation and cross-validation techniques.
* Familiarity with SQL and working with structured datasets.
* Strong problem-solving and analytical skills.

### Preferred Skills

* Experience with **PyTorch or TensorFlow**.
* Knowledge of **deep learning**, CNNs, RNNs, and Transformers.
* Familiarity with **NLP** and/or computer vision.
* Experience deploying models using **FastAPI or Flask**.
* Knowledge of Docker and cloud platforms such as AWS, Azure, or GCP.
* Familiarity with MLflow or other experiment/model-management tools.
* Understanding of MLOps and CI/CD pipelines.
* Experience with Git and collaborative software development.
* Knowledge of distributed computing frameworks such as Spark is a plus.

### Key Skills / Keywords

**Machine Learning, Python, Scikit-learn, Deep Learning, PyTorch, TensorFlow, Data Preprocessing, Feature Engineering, Model Deployment, MLOps, NLP, Computer Vision, SQL, Docker, AWS, Statistics, Pandas, NumPy, Model Evaluation**
